# Changelog

## 0.1.0

Primeira versão publicada.

- Catálogo de serviços em YAML com validação (`apimap validate`) e site estático (`apimap build`).
- Visualizador com grafo 2D, modo 3D, tema escuro e claro, busca, filtros, upstream/downstream e exportação em PNG.
- Descoberta automática a partir de repositórios locais ou git (`apimap scan`), com scanners para arquivos de configuração, .NET, Node, OpenAPI e docker-compose.
- Editor local (`apimap serve`) e propostas de mudança por pull request a partir do site publicado.
- `apimap link`, `apimap export --format mermaid` e `apimap diff`.
- Skills para agentes de IA em `skills/`.
